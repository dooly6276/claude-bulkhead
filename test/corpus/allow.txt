# Commands every guard must let through.
# Each line runs through every PreToolUse hook with a realistic payload (timeout 120000),
# cwd a clean temporary git repository on branch main, plenty of free RAM, and no other
# Claude session on the machine. `<NL>` stands for a newline inside one command.
# `#@ tool PowerShell` switches the tool name for the lines below it.
# `#@ state <name>` runs the lines below in another machine state (low-ram, busy-ports,
# shared-tree; see stateFor in harness.js) and `#@ state default` goes back to the quiet one.
# `#@ config {json}` gives the lines below a global config.json, until `#@ config none`.
# `#@ timeout 600000` sends a longer tool timeout with the lines below, `#@ timeout default` ends it.
# A trailing TAB + `# todo: reason` marks a known false positive in src/ (reported as a todo test).
